# [Iterative Inorder](https://www.geeksforgeeks.org/problems/inorder-traversal-iterative/1)
## Medium
Given a binary tree. Find the inorder traversal of the tree without using recursion.
Examples
Input: &nbsp;Output: 4 2 5 1 3
Explanation: Inorder traversal (Left-&gt;Root-&gt;Right) of the tree is [4, 2, 5, 1, 3].

Input:Output: 1 7 10 8 6 10 5 6
Explanation: Inorder traversal (Left-&gt;Root-&gt;Right) of the tree is [1, 7, 10, 8, 6, 10, 5, 6].
Constraints:

1 ≤ Number of nodes ≤ 105
1 ≤ Node data ≤ 105
